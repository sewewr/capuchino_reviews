# Сертификат Минцифры для GigaChat

GigaChat работает только с корневым сертификатом НУЦ Минцифры.

Бот при первом обращении к GigaChat сам скачивает его с
https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

Если сервер не может его скачать (бот напишет об этом), скачайте файл
по ссылке выше вручную и положите в эту папку под именем
`russian_trusted_root_ca.crt`. Это публичный сертификат, не секрет —
его можно хранить в репозитории.
