ФАЙЛЫ ПРОЕКТА — сверка с репозиторием на GitHub
================================================

Все перечисленное лежит внутри папки reviews-bot.
В Railway указан Root Directory = /reviews-bot, поэтому структуру
менять нельзя: файлы должны быть внутри этой папки, а не в корне.

КОРЕНЬ ПАПКИ (11 файлов)
  mailbox.py            чтение почты по IMAP
  pipeline.py           конвейер: почта - парсер - база - Telegram
  storage.py            база: филиалы, отзывы, дедупликация
  config.py             настройки из переменных окружения
  seed_branches.py      справочник 10 филиалов
  railway.json          команда запуска для Railway
  requirements.txt      список библиотек
  README.md             описание проекта
  .python-version       версия Python
  .gitignore            что не попадает в репозиторий
  .env.example          образец переменных (без настоящих паролей)

ПАПКА parsers (4 файла)
  __init__.py           реестр: выбор парсера по отправителю письма
  base.py               общая модель отзыва
  yandex_business.py    разбор писем Яндекс Бизнеса
  gis2_business.py      разбор писем 2ГИС

ПАПКА telegram_ui (3 файла)
  __init__.py           пустой, но НУЖЕН: без него папка не работает как модуль
  bot.py                бот: кнопки, статусы, фоновое чтение почты
  cards.py              карточка отзыва и клавиатура

ТЕСТЫ (5 файлов, на работу бота не влияют)
  test_parse.py         прогон парсеров на письмах
  test_pipeline.py      прогон конвейера целиком
  test_storage.py       прогон базы
  check_match.py        сверка адресов филиалов
  preview_cards.py      просмотр карточек без запуска бота

ВСЕГО: 23 файла

ЧЕГО В РЕПОЗИТОРИИ БЫТЬ НЕ ДОЛЖНО
  runtime.txt           УДАЛИТЬ — роняет сборку на Railway
  Procfile              УДАЛИТЬ — заменен на railway.json
  samples/              письма заказчика, не для репозитория
  .env                  настоящие пароли, не для репозитория
  __pycache__/          служебные файлы Python

ЧАСТАЯ ПРИЧИНА ПРОПАЖИ ФАЙЛОВ
Загрузка через "Add file - Upload files" на GitHub заменяет только те
файлы, которые перетащили. Если перетащить лишь часть, остальные
остаются старыми — но если перетащить папку целиком, она заменяется
целиком. Файлы, начинающиеся с точки (.gitignore, .env.example,
.python-version), в проводнике Windows скрыты и часто не попадают
в перетаскивание. Включи показ скрытых файлов перед загрузкой.
